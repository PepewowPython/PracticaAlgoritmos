=================================
CARACTERES Y OPERADORES PSEINT
=================================

ASIGNACION
----------
<-      Asignar valor

Ejemplo:
x <- 10

OPERADORES ARITMETICOS
----------------------
+       Suma
-       Resta
*       Multiplicacion
/       Division
^       Potencia

Ejemplos:
a + b
a - b
a * b
a / b
a ^ 2

OPERADORES RELACIONALES
-----------------------
=       Igual
<>      Diferente
<       Menor que
>       Mayor que
<=      Menor o igual
>=      Mayor o igual

Ejemplos:
a = b
a <> b
a < b
a > b
a <= b
a >= b

OPERADORES LOGICOS
------------------
Y       AND
O       OR
NO      NOT

Ejemplos:
a > 0 Y b > 0
a > 0 O b > 0
NO(a = b)
